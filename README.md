# Bachelor's Electrical Engineering Course Projects

Projects I completed during my undergraduate Electrical Engineering studies at Yazd University.
They cover software, microcontroller programming, and digital hardware design.

My bachelor's thesis is in a separate repository:
[MRI-image-segmentation-using-3DU-Net](https://github.com/AlirezaKalbassi/MRI-image-segmentation-using-3DU-Net).

## Projects

| Project | Course | What it is | Tools |
|---|---|---|---|
| [Introductory programming's final project](Introductory%20programming's%20final%20project) | Introductory Programming | A console maze game with moving obstacles, lives, and win/lose screens | C++, Windows console API |
| [Digital systems 2 (final project)](Digital%20systems%202%20%28final%20project%29) | Digital Systems 2 | A digital clock with time-setting buttons on the AT89C51 microcontroller | 8051 assembly, Keil uVision, Proteus |
| [FPGA course's final project](FPGA%20course's%20final%20project) | FPGA | A UART receiver that shows three received characters on a multiplexed 7-segment display | Verilog, Xilinx ISE, Spartan-6 |

Each folder has its own README with a description, instructions for running it, and the main design ideas.

## What these projects show

- **Software:** structured C++ programming, real-time keyboard input, and game logic with collision detection.
- **Microcontrollers:** low-level 8051 assembly, I/O ports, push-button input, and simulating the circuit in Proteus.
- **Digital design:** finite state machines, serial (UART) communication, and display multiplexing in Verilog on an FPGA.
